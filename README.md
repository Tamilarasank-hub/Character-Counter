# Character-Counter
## Real-Time Character Counter

A simple and interactive web application built using HTML, CSS, and JavaScript that counts the number of characters entered in a text area in real time.

### Features
- Real-time character counting as the user types.
- Displays the total characters entered and remaining characters.
- Maximum character limit of 200 characters.
- Warning message when the character limit is reached.
- User-friendly and responsive interface.

### Technologies Used
- HTML5
- CSS3
- JavaScript

### Learning Outcomes
Practiced DOM manipulation, event listeners, conditional statements, and dynamic content updates using JavaScript.
